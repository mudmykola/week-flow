# Локалізація WeekFlow

WeekFlow використовує `@nuxtjs/i18n` зі словниками `i18n/locales/uk.json` та `en.json`.

- Українська — мова за замовчуванням.
- URL не мають мовного префікса (`strategy: no_prefix`).
- Locale-файли завантажуються окремо та prerender-яться у статичні assets.
- Вибір мови зберігається у cookie `weekflow-locale` та в налаштуваннях акаунта.
- Новий користувацький текст додається в обидва словники; UI використовує `$t()` або `useI18n().t`.
- Тест `tests/i18n/locales.test.ts` не дозволяє словникам розійтися за ключами.
